# Vide Placard - Vaisselle de Seconde Main au Sénégal

Bienvenue sur **Vide Placard**, la première marketplace de vaisselle d'occasion au Sénégal.

## À propos du projet

Vide Placard permet aux utilisateurs d'acheter et de vendre leur vaisselle d'occasion (bols, marmites, théières, etc.) à des prix imbattables. Le projet vise à promouvoir l'économie circulaire et à faciliter l'équipement des cuisines sénégalaises.

## Technologies utilisées

- **Vite** : Outil de construction rapide pour le frontend.
- **React** : Bibliothèque JavaScript pour construire l'interface utilisateur.
- **TypeScript** : Pour un typage statique et une meilleure maintenabilité.
- **Tailwind CSS** : Pour un design moderne et réactif.
- **Supabase** : Pour l'authentification et la gestion de la base de données.
- **shadcn/ui** : Composants d'interface utilisateur réutilisables.

## Installation locale

1. Clonez le dépôt.
2. Installez les dépendances :
   ```sh
   npm install
   ```
3. Lancez le serveur de développement :
   ```sh
   npm run dev
   ```

## Déploiement

Le site est conçu pour être déployé sur des plateformes comme Netlify, Vercel ou via des serveurs personnalisés supportant Node.js.
